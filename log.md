    *   **The Multi-State Machine Realization**: Identified an architectural tension where responsibility for marshalling the model was fragmented across Bubbletea commands, the daemon's HTTP streaming loop, SQLite syncs, and the model's own token generation. Discovered that the TUI's rock-solid stability was an artifact of Bubbletea's single-threaded event loop, while the daemon's concurrent HTTP goroutines were causing state tearing across shared in-memory graph pointers and storage transactions.
    *   **Canonical `SessionHarness` ([internal/engine/harness.go](internal/engine/harness.go))**: Unified the multi-turn agent execution lifecycle (`BuildLLMContext` $\rightarrow$ `GenerateResponseStream` $\rightarrow$ `ExecuteToolCall` $\rightarrow$ `UpdateAssistantObservations` $\rightarrow$ `ExtractSignat` $\rightarrow$ `SaveSessionHead`) into a single, canonical engine runner. Emits typed events (`token`, `thought`, `tool_call`, `tool_result`, `node_complete`, `error`) over an asynchronous channel. Validated with comprehensive unit tests in [harness_test.go](internal/engine/harness_test.go).
    *   **Per-Session Actor Mailboxes ([internal/server/session_actor.go](internal/server/session_actor.go))**: Introduced dedicated `SessionActor` workers in the daemon. Each named session (`main`, `session-alpha`, `beta`) owns a private, serialized FIFO queue. Incoming requests for the same session execute strictly sequentially, completely replicating Bubbletea's single-threaded stability inside the daemon and preventing observation stomping during rapid follow-ups.
    *   **Reactive SSE Event Pump**: Slashed [stream.go](internal/server/stream.go) by over 50%, transforming `handleChatStream` from a complex, 457-line state machine into a thin, reactive SSE pump that forwards events from the session actor's channel.
    *   **Livefire Multi-Session Validation**: Successfully validated simultaneous multi-session operations (`alpha` and `beta` running concurrently against `please serve -c ./livefire.json`) and autonomous narrative vectors (`make test-livefire`), with 100% test passage across the repository.
