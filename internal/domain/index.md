# Domain Models

Shared domain models and core types used across the `please` project. This package provides a centralized definition of the project's primary data structures to ensure consistency between the server, TUI, and internal engine.

## Core Definitions

* **Messages**: Core structures for LLM and User messages.
* **Tool Calls & Observations**: Standardized definitions for tool invocation and the resulting observations (outputs).
* **Smart Receipts**: Schemas for "Smart Receipts" used to track tool execution and verify state changes.
* **Common Types**: Foundational utility types used throughout the project's internal and external APIs.
